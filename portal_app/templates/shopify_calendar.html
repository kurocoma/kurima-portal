    初回設定（テーマの付け替え・1回だけ）

    このページで1回反映して {{ current_filename }} と {{ next_filename }} を Shopify に作ったあと、テーマエディタで次の4か所を付け替えます。以後は付け替え不要です。

    1. Shopify 管理画面 → オンラインストア → テーマ → 公開中テーマの「カスタマイズ」
    2. サイドバー（PCで表示）の「営業日カレンダー」ブロック1つ目の画像 → {{ current_filename }}
    3. サイドバーのカレンダーブロック2つ目（休業日の案内文つき）の画像 → {{ next_filename }}
    4. トップページの「営業日カレンダー」セクション（SPのみ表示）の画像1つ目 → {{ current_filename }}、2つ目 → {{ next_filename }}
    5. 同じセクションの画像2つの「幅」をどちらも 100% にそろえる（SPで2枚とも画面幅いっぱいに表示されます）
    6. 保存 → PC とスマホでストアを開き、今月・来月が表示されることを確認

    設定が終わると、上の「Shopify の状態」に「テーマ設定: 完了」と表示されます（read_themes 権限がある場合）。
